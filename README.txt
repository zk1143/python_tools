## 為什麼寫這個？

每個月都要處理一份 **15 個分頁的 KPI 報表**：  
- 修復率、滲透率、QOS、換機、測速…  
- 手動複製貼上 → 很容易出錯  
- 百分比 `0.75` 要變 `75.00%` 給網頁用  
- 還要切成 CSV 丟進 PHP 資料夾  

**所以寫了這 50 行小程式，救救自己**

---

## 功能一覽（目前會做的）

| 功能 | 說明 |
|------|------|
| **一鍵讀全部 sheet** | 15 個分頁一次搞定 |
| **自動格式化百分比** | `0.75` → `75.00%`，支援「率」「滲透」「達成」等欄位 |
| **UTF-8 輸出** | Excel 開不亂碼，PHP 直接讀 |
| **自動建 `data/` 資料夾** | CSV 整齊放好 |
| **可自動複製到 PHP** | 設路徑就一鍵部署 |

---

## 怎麼用？（超簡單 3 步）

```bash
1. 把你的 Excel 放進資料夾，改名為 `demo_report.xlsx`
   （或打開 `exceltocsv.py` 第 8 行改名字）
2. 雙擊 `exceltocsv.py`（或用命令列執行）
3. 成功！CSV 自動出現在 `data/` 資料夾


超重要!!
1. 0-1% 會出問題？
對！ 有些報表是 0.064（6.4%），但 Excel 顯示 6.4%，複製出來變 0.064
解決：程式會 自動偵測含「率」「滲透」的欄位，一律轉成 6.40%

2. 100% 變 1.00%？
對！ 如果原始是 1（代表 100%），會變 100.00%
解決：程式 只處理 0~1 的數字，大於 1 就跳過

3. 怎麼避免誤判？
程式用 關鍵字匹配，只處理含這些字的欄位：
率、滲透、達成、平均
其他欄位（如數值、狀態）完全不動

4.
月份格式：用 2025年11月，不要用 2025/11（Excel 會變日期）
有空值填 0：避免 #DIV/0!
備註寫清楚：下個月自己謝謝自己
